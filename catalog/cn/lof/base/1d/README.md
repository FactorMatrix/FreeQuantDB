# LOF 日线

`cn/lof/base/1d` 已发布 2005-01-04 至 2025-12-31 的 21 个年包，共 945,361 行，覆盖沪深 452 只 LOF。每行对应一个标的的一个交易日。[2025 年包](2025/2025.parquet.json) · [数据格式](../../../../../docs/MARKET_DATA.md)

日线包含 9 列。`instrument` 为六位代码及 `.SH` 或 `.SZ` 交易所后缀，`trading_date` 为交易日，`open`、`high`、`low`、`close` 为未复权的开高低收，`volume` 为成交份额，`amount` 为人民币成交额，`prev_close` 为前收盘参考价。

同一证券代码在基金转型前有有效交易记录时，历史按原交易日保留。有效的零成交日线也保留。分红或转换期间，前收盘参考价可发生变化。历史复权需结合生效日和事件口径核对。

`502020.SH` 在 2018-12-19 的前收盘参考价为 `0.830`。`502048.SH` 在 2015-04-27 的成交额与当天成交量及价格区间存在差异，成交额待核对。
