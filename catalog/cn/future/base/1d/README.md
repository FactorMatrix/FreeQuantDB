# 国内期货日线

`cn/future/base/1d` 已发布 2005-01-04 至 2025-12-31 的 21 个年包，共 2,137,788 行、9,852 个合约。每行对应一个具体合约的一个交易日，年包按交易日年份划分。[字段与目录](../../../../../docs/MARKET_DATA.md) · [2025 年包](2025/2025.parquet.json)

合约覆盖以挂牌和最后交易日为界，保留最后交易日的有效日线及有效零成交记录。成交量以手计，价格按合约报价单位记录。部分早期记录有成交量且成交额记为零。

## 字段

期货日线包含 9 个通用字段和 5 个期货字段，共 14 列。`close` 为收盘价，`prev_close` 为前收盘参考价。结算价格分别记录在以下字段中。

| 字段 | 含义 |
| --- | --- |
| `settlement` | 当日结算价 |
| `prev_settlement` | 上一交易日结算价 |
| `open_interest` | 持仓量，单位为手 |
| `limit_up` | 涨停价 |
| `limit_down` | 跌停价 |

历史记录中，结算价、昨结算价及涨跌停价记为 0 时按缺少有效价格处理。持仓量可以为 0。

升级到支持 14 列期货日线的 FQDB 后，可先运行 `fqdb service stop` 结束旧进程，再运行 `fqdb catalog refresh` 获取新版年包的磁力链接。
