# 中国股票日线

数据集为 `cn/stock/base/1d`。公开的 21 个年包覆盖 2005-01-04 至 2025-12-31。各年实际覆盖和最新磁力链接见[发布目录](../../../../index.json)。

## 字段

每行对应一个标的的一个交易日，以 `instrument` 和 `trading_date` 为联合键。行情价格为未复权日线。

| 字段 | 类型与含义 |
| --- | --- |
| `instrument` | 字符串，包含交易所后缀的证券代码 |
| `trading_date` | 日期，交易日 |
| `open`、`high`、`low`、`close` | 双精度，开盘、最高、最低、收盘价 |
| `volume`、`amount` | 双精度，成交量和成交额 |
| `prev_close` | 双精度，前收盘参考价，除权除息时可与上一交易日收盘价不同 |

## 停牌与退市

- 停牌期间保留已有日线。成交量和成交额可为零，价格字段仍可有值。日线表没有停牌标记。
- 已修订的连续停牌记录若当日复权比例为 1，`prev_close` 与上一交易日的 `close` 一致。可核实的除权除息日保留应有的复权比例。修订只涉及 `prev_close`，该字段可有多于两位的小数。
- 退市前的历史保留。退市生效日起不再纳入新整理的记录。现有历史快照有一条退市生效日的旧记录，生效日之后未发现记录。

按期间下载时使用目录中当前的磁力链接。修订后的包有新的磁力标识。[2025 年包](2025/2025.parquet.json)
