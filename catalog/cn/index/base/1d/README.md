# 指数日线

`cn/index/base/1d` 覆盖 2005-01-04 至 2025-12-31。21 个年度 Parquet 包包含 6,712 个指数、22,994,743 条日线记录。指数各自的起始日期和交易日期有差异。[2025 年包](2025/2025.parquet.json) · [数据格式](../../../../../docs/MARKET_DATA.md)

| 系列 | 代码示例 |
| --- | --- |
| 交易所市场指数 | 上证指数 `000001.SH`、深证成指 `399001.SZ`、北证50全收益 `899050CNY01.INDX` |
| 中证、国证指数 | 沪深300 `000300.SH`、中证A500 `000510.SH`、国证1000 `399311.SZ` |
| 行业指数 | 申万 651 个、中信 590 个，例如申万农林牧渔 `801010.INDX`、中信石油石化 `CI005001.INDX` |
| 其他机构系列 | 华证A指微盘 `999004.INDX` |

`instrument` 是指数代码，`trading_date` 是指数观察日期。部分跨市场指数的日期与 A 股交易日不同。指数正式发布前已有的历史回算也可能包含在年包内。

`open`、`high`、`low`、`close` 和 `prev_close` 按指数点表示。`prev_close` 是前收盘参考点位，可能与上一条观测记录的收盘点位不同。仅有收盘点位的系列保留 `close`。缺失的开盘、最高、最低、量额和前收盘参考点位以 `null` 表示，其中 4,694 条记录缺少前收盘参考点位。

`volume` 与 `amount` 是各指数记录的汇总量额。成交量单位与成交额币种依指数而异，跨指数比较前需要核对各自口径。价格指数、全收益和净收益系列按各自公布的定义使用。[中证指数计算规则](https://oss-ch.csindex.com.cn/contract/cms_add/20240726155028-%E3%80%8A%E4%B8%AD%E8%AF%81%E6%8C%87%E6%95%B0%E6%9C%89%E9%99%90%E5%85%AC%E5%8F%B8%E8%82%A1%E7%A5%A8%E6%8C%87%E6%95%B0%E8%AE%A1%E7%AE%97%E8%A7%84%E5%88%99%E3%80%8B.pdf)

fqdb catalog refresh
fqdb download cn/index/base --frequency 1d --year 2025
